Projects

⚠️Nur für Administratoren — Projekte können ausschliesslich von Administratoren erstellt, bearbeitet und gelöscht werden.

Verwaltung

Create New Project

Administratoren können neue Projekte direkt über das Projects Menü erstellen.

Create New Project Dialog — Projektname und optionale Beschreibung definieren.

Create Project Dialog

FeldBeschreibung
Project NameDefiniert den eindeutigen Namen des Projekts.
DescriptionOptionale Projektbeschreibung für organisatorische Zwecke.

Create Project Action

Der Create Project Button erstellt den neuen Projektcontainer und initialisiert die Projektstruktur (Workflows, Pages, Schedules, etc.).

Regeln für den Projektnamen

  • 3 bis 100 Zeichen.
  • Erlaubt sind Buchstaben aller Sprachen — auch Umlaute, ß und Akzente —, Ziffern, Leerzeichen sowie - _ . ( ) &. Namen wie „Qualitätssicherung (Süd) & Co.“ lassen sich also anlegen.
  • Nicht erlaubt sind Zeichen wie < > / \ " ' ; %.

Lehnt der Server den Namen oder eine andere Eingabe ab, nennt der Dialog den Grund — es erscheint keine Erfolgsmeldung.

Bearbeitbare Felder

FeldBeschreibung
Project NameDer Projektname kann jederzeit umbenannt werden.

Delete Project

Administratoren können Projekte entfernen, die nicht mehr benötigt werden.

⚠️Wichtige Hinweise — Das Löschen eines Projekts kann folgende Inhalte entfernen: Workflows, Runs, Pages, Test Data, Schedules sowie generierte Assets. Die genauen Auswirkungen sind abhängig von der Systemkonfiguration und den Retention Policies.

Fehler beim Speichern

Für den neuen Namen gelten dieselben Regeln wie beim Anlegen (siehe Create New Project). Wird eine Änderung abgelehnt — im Dialog Edit Project ebenso wie in den Projekteinstellungen —, nennt Autemos den Grund; die Eingabe bleibt zum Korrigieren stehen, und der bisherige Projektname wird nicht überschrieben.

Funktionen

Navigation Shortcuts & Isolation

Jede Project Card bietet direkte Navigations-Shortcuts zu wichtigen Projektbereichen, und jedes Projekt ist vollständig isoliert.

Test Workflow Navigation

Benutzer können direkt das Test Workflow Menü öffnen. Dies ermöglicht schnellen Zugriff auf:

  • Workflow-Bearbeitung
  • Workflow-Ausführung
  • Wartung der Automatisierung

Code Generation Navigation

Benutzer können direkt das Code Generation Menü öffnen. Dies ermöglicht schnellen Zugriff auf:

  • Generierten Automatisierungscode
  • Framework-Exporte
  • AI-generierte Automatisierungs-Assets

Project Isolation

Jedes Projekt verwaltet isolierte:

  • Workflows
  • Page Objects
  • Fields
  • Schedules
  • Automatisierungs-Assets

Vorteile der Isolation

  • Saubere Organisation
  • Skalierbarkeit
  • Unterstützung mehrerer Teams
  • Klare Verantwortlichkeitstrennung

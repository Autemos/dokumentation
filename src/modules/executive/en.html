Executive Dashboard

Executive KPIs

Executive Overview

The Executive Overview displays central KPIs to assess the overall state of the test automation platform.

Executive Overview — central KPIs (Pass Rate, Tests Executed, Coverage, Flaky Rate) at a glance.

Key Metrics

Pass Rate

Overall success rate of all test executions (e.g., 95.2%). Evaluates test stability, release readiness, and reliability.

Tests Executed

Total number of tests executed within the selected period — portfolio activity and automation tracking.

Test Coverage

Automation coverage of critical business processes and flows — for risk analysis and gap identification.

Flaky Rate

Proportion of unstable or inconsistent tests. High values indicate unstable environments, synchronization issues, weak selectors, or infrastructure problems.

Platform & Usage

Platform Features

The Executive Dashboard combines three strategic platform capabilities: real-time monitoring, cross-project visibility, and integrated AI analytics.

Real-Time Monitoring

The Executive Dashboard is designed for near-real-time monitoring — with live updates, dynamic metrics, and continuous infrastructure monitoring.

Cross-Project Visibility

Unlike project-specific dashboards, the Executive Dashboard aggregates global data across:

  • All projects
  • All schedules
  • All executions
  • All environments
  • All infrastructure nodes

AI & Automation Insights

The dashboard integrates AI-related metrics such as:

  • LLM costs
  • AI-generated tests
  • AI-driven executions
  • AI-based quality analysis

This provides transparency over automation quality and AI operational costs.

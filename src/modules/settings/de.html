Global Settings

⚠️Nur für Administratoren — Der Bereich Global Settings ist ausschliesslich für Systemadministratoren zugänglich. Änderungen wirken sich auf alle Projekte, Benutzer und das globale Systemverhalten aus. Falsche Konfigurationen können Stabilität, Sicherheit, Ausführungsumgebungen oder verbundene Dienste beeinträchtigen.

Das Modul Global Settings bietet eine zentrale Verwaltung aller systemweiten Konfigurationen innerhalb der gesamten Autemos-Plattform. Alle Einstellungen gelten global für sämtliche Projekte und Umgebungen.

Global Settings — zentrale Verwaltung aller plattformweiten Konfigurationen.

Kommunikation

Notification Settings

Der Reiter Notifications konfiguriert zentral die Mail-Anbindung der Plattform. Sie wird für Benachrichtigungen zu Testläufen (siehe Modul Notifications) und für alle System-Mails verwendet. Weitere Kanäle wie Microsoft Teams folgen separat.

Abschnitt „E-Mail“

EinstellungBeschreibung
Enable email notificationsSchaltet E-Mail-Benachrichtigungen zu Testläufen ein oder aus. System-Mails hängen nicht an diesem Schalter, sondern nur an einer vollständigen Mail-Konfiguration.
Mail providerAuswahl zwischen SMTP und Microsoft Graph (Microsoft 365 / Outlook).
SMTPServer, Port, Security (STARTTLS, SSL/TLS oder None), Benutzername, Passwort und Absenderadresse. Bleibt das Feld für den SMTP-Server leer, verwendet Autemos die Mail-Konfiguration des Servers („Leave SMTP server empty to use the server mail configuration“).
Microsoft GraphTenant-ID, Client-ID, Client-Secret und Absenderadresse einer App-Registrierung mit der Anwendungsberechtigung Mail.Send.
Send test emailVersendet eine Testmail an Ihre eigene Adresse — mit den gespeicherten Einstellungen. Die Antwort meldet Erfolg oder einen kurzen Grund, nie ein Geheimnis oder einen Stacktrace.
🔒Passwörter und Client-Secrets werden verschlüsselt gespeichert und nie im Klartext zurückgegeben. Gespeicherte Werte erscheinen als „•••• (stored)“.

Abschnitt „Recipients“

Mit dem Schalter Also notify project admins on failed runs (Standard: aus) erhalten zusätzlich die Admins des Projekts eine Meldung, wenn ein Lauf fehlschlägt. Die Empfängerlogik ist im Modul Notifications beschrieben.

System-Mails

Passwort-Reset, „Passwort geändert“, Einladungen und Admin-Reset-Links werden über die hier konfigurierte Anbindung versandt, sobald sie für den gewählten Provider vollständig ist. Andernfalls verwendet Autemos die Mail-Konfiguration des Servers. Scheitert der gewählte Weg, gibt es keinen zweiten Versuch über einen anderen Weg — der Fehler wird ohne Mail-Inhalt protokolliert.

Audit Logs

⚠️Nur für Administratoren — Die Seite Audit Logs ist globalen Administratoren vorbehalten. Andere Benutzer werden zum Dashboard umgeleitet.

Die Admin-Navigation zeigt unter Global Settings den Punkt Audit Logs. Die Seite ist ein schreibgeschütztes Protokoll aller Benutzer- und Systemaktionen — etwa Code-Sync, Einstellungsänderungen, Secret-Aktionen, Screenshot-Aufräumläufe und Passwortänderungen.

Audit Logs — Filter, Tabelle und Export CSV.

Filter und Suche

FilterBeschreibung
SearchFreitextsuche; wirkt zusammen mit den übrigen Filtern.
From / ToZeitraum in ganzen Tagen.
ResultErfolgreiche oder fehlgeschlagene Aktionen.
User, Event, Category, ProjectListenfilter; „All“ hebt den Filter auf.

Filter und Sortierung arbeiten auf dem Server; die Liste ist seitenweise (Standard 50 Einträge, höchstens 200 pro Seite) und standardmässig nach Zeit absteigend sortiert. Passt kein Eintrag, erscheint „No audit events match the current filters“.

Tabelle und Details

Die Tabelle zeigt Timestamp, User, Event, Category, Object, Action, Result und einen Knopf Details. Der Details-Dialog nennt zusätzlich Event ID, Projekt, Fehlermeldung, technische Angaben (Methode, Pfad, IP, Quelle), die bereinigten Parameter sowie alte und neue Werte, falls vorhanden. Kategorien sind u. a. Code Sync, Administration, Security und Test Management; Ereignisse ohne Zuordnung stehen unter Other. Hintergrundereignisse ohne Anmeldung tragen den Benutzer „System“.

Export

Export CSV lädt alle Einträge, die zu den aktiven Filtern passen — nicht nur die sichtbare Seite — mit Kopfzeile.

Sicherheit

  • Die Seite bietet kein Bearbeiten und kein Löschen; die Datenbank verhindert nachträgliche Änderungen an Einträgen.
  • Passwörter, Tokens und verschlüsselte Einstellungswerte erscheinen weder in Tabelle noch im Dialog noch im CSV-Export; sie sind maskiert.
  • Ein Fehler beim Schreiben des Audit-Eintrags bricht die eigentliche Aktion nicht ab.

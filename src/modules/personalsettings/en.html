Personal Settings

The Personal Settings module allows users to manage their own account information and personal certificate configurations. It is accessible via the user avatar in the top right of the platform.

Personal Settings — accessible via the user avatar in the top right.

Features

Personal Profile Information

Overview of your own account details.

Personal Runtime Certificates

Management of individual mTLS certificates.

Personal Certificate Sources

Your own file system or vault sources.

mTLS Client Certificates

Secure client authentication against protected applications.

Available Actions

  • Open personal settings
  • View profile information
  • Manage personal certificates
  • Manage personal runtime sources
  • Log out from the platform

Certificates & Sources

Certificates

The Certificates section manages personal runtime certificate configurations. Certificates are stored separately from shared project configurations.

It Enables

  • Storage of personal mTLS certificates
  • Configuration of personal runtime file or vault sources
  • Use of individual certificates for secure API communication
  • Testing of mTLS-protected applications with personal identity
Add Certificate Source — add runtime source for personal certificates.
Certificates & Sources

Personal Sources

Personal Sources define user-specific runtime storage locations for certificates and secure files.

Useful When

  • Users should not use global/shared certificate sources
  • Personal vault credentials are required
  • Team-independent certificate management is needed
Add Personal Certificate — add personal certificate with source selection.

Supported Source Types

File System Source

Local directory as source.

Shared File Shares

Network share or mounted path.

Vault-based Sources

Certificates & Sources

Personal Certificates

Personal Certificates are used for secure client authentication against mTLS-protected applications. Certificates reference a runtime source and can optionally be password-protected.

Supported Certificate Formats

  • PKCS#12 (.p12 / .pfx)

Certificate Configuration

ParameterDescription
NameName of the certificate profile
DescriptionOptional description
Certificate SourceReference to the runtime source
Certificate TypeCertificate format
Certificate FileUploaded certificate file
PasswordOptional certificate password
Allowed OriginsAllowed target domains

Allowed Origins

Allowed Origins restrict the use of a certificate to defined target systems. Example: https://example.com. This increases security by allowing certificates to be used only for approved domains.

⚠️Security note — Certificates and secrets are processed securely at runtime.

Best Practices

  • Use separate certificates per environment
  • Restrict Allowed Origins as much as possible
  • Do not share personal certificates
  • Protect certificates with a password
  • Rotate certificates regularly

Logout

Users can log out from the platform directly via the avatar menu in the top right.

On Logout

  • The current session is terminated
  • The active user context is cleared
  • The user returns to the login screen

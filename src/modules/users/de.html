User Management

⚠️Nur für Administratoren — Der Bereich User Management ist ausschliesslich für Administratoren zugänglich. Nur Benutzer mit administrativen Berechtigungen können Benutzer einladen, bearbeiten, deaktivieren, löschen, Projekte zuweisen und Rollen verwalten. Dies gewährleistet eine sichere und zentralisierte Zugriffskontrolle innerhalb der gesamten Autemos Plattform.

Das User Management Menü ist der zentrale Administrationsbereich zur Verwaltung aller Benutzer innerhalb von Autemos.

Was Administratoren können

  • Benutzer erstellen und einladen
  • Benutzerkonten verwalten
  • Projektzugriffe zuweisen
  • Projektrollen konfigurieren
  • Benutzeraktivitäten überwachen
  • Plattformberechtigungen steuern

Entwickelt für

Enterprise Access Management

Zentrale Kontrolle für grosse Organisationen.

Multi-Team-Umgebungen

Saubere Trennung mehrerer Teams.

Sichere Projektisolation

Granulare Zugriffskontrolle pro Projekt.

Skalierbare Berechtigungen

Auch bei sehr grossen Benutzerzahlen.

Zweck

Der Bereich User Management unterstützt Organisationen dabei:

Benutzerrollen

Benutzer können unterschiedliche systemweite Rollen besitzen:

Administrator

Vollständige Plattform-Verwaltungsrechte.

User

Standard-Benutzerkonto mit projektbezogenen Rechten.

Die Rollen definieren Plattformberechtigungen, Verwaltungsfunktionen und Zugriffseinschränkungen.

Benutzerstatus

Active

Benutzer kann sich anmelden und arbeiten.

Disabled

Benutzer ist gesperrt — kein Login möglich.

Suchfunktion

Die Suchleiste ermöglicht Administratoren das schnelle Auffinden von Benutzern. Unterstützte Suchkriterien:

  • Name
  • Username
  • E-Mail-Adresse

Benutzer aktivieren / deaktivieren

Administratoren können Benutzer aktivieren oder deaktivieren. Deaktivierte Benutzer:

  • Können sich nicht mehr anmelden
  • Verlieren den Plattformzugriff
  • Behalten historische Referenzen innerhalb des Systems

Benutzer löschen

Administratoren können Benutzer dauerhaft aus dem System entfernen.

⚠️Wichtige Hinweise — Beim Löschen eines Benutzers werden Berechtigungen sofort entfernt. Historische Test-Zuweisungen können erhalten bleiben, und Audit-Logs können weiterhin Referenzen speichern.

Projektrollen

Projektbezogene Rollen können sein:

Owner

Vollständige Projektverantwortung und administrative Kontrolle.

Admin

Kann Projektressourcen und Konfigurationen verwalten.

Member

Standardzugriff zur Zusammenarbeit innerhalb des Projekts.

Viewer

Nur lesender Zugriff auf Projektinformationen.

Projektberechtigungen

Projektrollen definieren den Zugriff auf:

  • Workflows
  • Test Runs
  • Pages
  • Schedules
  • Test Data
  • Automation Assets

Dies gewährleistet Projektisolation, kontrollierte Zusammenarbeit und sicheren Multi-Team-Betrieb.

Pages, Fields & Table Definitions

Das Pages-Modul bietet zentralisiertes Management für wiederverwendbare technische UI-Elemente, die in automatisierten Workflows verwendet werden. Es fungiert als technische Grundschicht für Workflows, indem es wiederverwendbare PageObjects, Feld-Selektoren und geschäftsfreundliche Table Definitions organisiert.

Was das Modul bietet

  • Wiederverwendbare PageObjects für Anwendungsseiten verwalten
  • Zentralisiertes Selector- und Feld-Management
  • Wiederverwendbare Geschäftstabellen-Abstraktionen
  • Selector-Validierung und automatische Wartung
  • Selector- und Caching-Konfiguration auf Projektebene

Page-Screenshots

Pages

Zu jeder Page lässt sich ein Bildschirmfoto hinterlegen. So ist ohne Rätseln klar, welche Seite gemeint ist: gross in der Detailansicht und als Vorschaubild in der Pages-Liste. Das Bild kann von Hand hochgeladen werden oder entsteht automatisch während einer Aufnahme.

Screenshot hinterlegen

  • In den Dialogen Create New Page und Edit Page wählt das Feld Screenshot eine PNG- oder JPEG-Datei (höchstens 5 MB). Nach der Auswahl zeigt der Dialog eine kleine Vorschau.
  • Create beziehungsweise Update speichert zuerst die Page und lädt danach das Bild hoch. Scheitert der Upload (z. B. «File too large (max. 5 MB)» oder «Not a valid PNG/JPEG image»), bleibt der Dialog offen und nennt den Grund; die Page-Daten sind dann bereits gespeichert, ein vorhandenes Bild bleibt unverändert.
  • Der Dateityp wird am Inhalt erkannt, nicht an der Endung. Autemos komprimiert das Bild (JPEG, höchstens 1280 Pixel breit) und erzeugt ein Vorschaubild; ein Bild, das danach noch grösser als 1 MB ist, wird abgelehnt.
  • Ein neues Bild in Edit Page ersetzt das alte (ohne Historie). Remove screenshot (nur sichtbar, wenn ein Bild existiert) entfernt es beim nächsten Update. Wird die Page gelöscht, verschwindet auch das Bild.
  • Es gelten dieselben Rechte wie beim Bearbeiten der Page.

OrtDarstellung

Automatisch beim Aufnehmen

Legt ein Recorder beim Aufnehmen eine Page an oder verwendet er eine Page ohne Bild, hinterlegt er im Hintergrund automatisch ein Bild der Seite, auf der aufgenommen wurde. Ein vorhandenes Bild, ob von Hand oder automatisch, wird dabei nie überschrieben. Die Aufnahme wird nicht ausgebremst; ein Fehler beim Bild bricht nichts ab und zeigt keine Meldung.

RecorderVerhalten
Passive Recorder (Web)Beim ersten Ereignis auf einer neuen Page wird das Bild dieser Seite vorgemerkt (höchstens 20 je Sitzung) und beim Speichern der Pages abgelegt. Bei einer mehrseitigen Aufnahme zeigt jede Page ihre eigene Seite.
KI-Recorder (Web)Eine neu zugeordnete Page erhält ein Bild ihrer Seite. Navigiert die Aktion weg, entsteht kein falsches Bild; es wird bei der nächsten Zuordnung nachgeholt.
Mobil-RecorderTippt man während der Aufnahme ein Element an, das in einer Page ohne Bild liegt, wird das Geräte-Bild von vor dem Tap abgelegt (auch beim langen Drücken). Für die generische Page «IOSPage» und ausserhalb der Aufnahme entsteht kein Bild.
💡 Ein automatisch erzeugtes Bild lässt sich jederzeit über Edit Page durch ein eigenes Bild ersetzen.

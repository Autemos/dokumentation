Getting Started

Grid Dashboard

The Grid Dashboard provides a centralized real-time overview of all configured browser and mobile execution environments within Autemos. It helps teams monitor and manage their automation infrastructure efficiently.

Grid Dashboard — centralized overview of all connected browsers, mobile devices, cloud providers, and active sessions.

What the Dashboard Visualizes

  • Available browsers
  • Connected mobile devices
  • Cloud providers
  • Active sessions
  • Capacity usage
  • Device status

Purpose

The Grid Dashboard is designed to:

  • Monitor execution infrastructure health
  • Visualize available execution capacity
  • Display connected browsers and devices
  • Show active and available sessions
  • Provide operational transparency for test execution environments

Dashboard Sections

The dashboard is divided into multiple logical sections to provide quick access to the most important infrastructure information.

Provider Overview

The top section displays all configured providers and their availability. Examples:

  • Local
  • Experitest
  • Cloud providers

Type Filters

Users can filter execution environments by:

FilterDescription
DesktopShow only desktop browsers
MobileShow only mobile environments
Real DevicesShow only physical devices
AllShow all execution environments

This simplifies navigation in larger infrastructures.

Dashboard

Infrastructure Metrics

Four central metrics provide an at-a-glance overview of the capacity and utilization of the entire infrastructure.

Total Devices

Total number of configured devices and number of available devices. Example: 12 Total Devices, 2 available.

Active Sessions

Currently running sessions and maximum session capacity. Example: 1 of 6 max.

Available Slots

Remaining execution capacity and total free slots across all providers.

Cloud Providers

Number of configured cloud providers and active provider connections.

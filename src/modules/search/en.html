Test Search

The Test Search menu provides a centralized search and discovery interface for all tests within Autemos. It is designed to enable fast transparency across large automation portfolios.

Test Search Overview — central table view of all tests with search, filters, and pass-rate visualization.

What the Feature Enables

  • Find tests quickly
  • Analyze test status
  • Monitor execution quality
  • Filter failed or flaky tests
  • View test details
  • Navigate directly to related Test Runs

Purpose

The Test Search feature helps teams to:

  • Find tests across projects
  • Monitor test quality
  • Identify failed or unstable tests
  • Analyze execution statistics
  • Navigate quickly to executions
  • Improve debugging workflows
  • Create portfolio-wide transparency

Filter Options

The Test Search page offers fast filter options:

All

Show all tests.

Passed

Only successfully executed tests.

Failed

Only failed tests.

Flaky

Only unstable tests with inconsistent behavior.

Purpose of Filters

  • Isolate unstable tests
  • Detect failures faster
  • Analyze flaky behavior
  • Focus on stable executions

Visibility

Cross-Project Visibility

The Test Search feature operates across all accessible projects — a true portfolio-wide discovery interface.

💡This enables users to search for tests across projects without first having to select the correct project — ideal for QA teams managing multiple projects in parallel.

Capabilities

  • Search globally
  • Compare tests
  • Identify duplicate tests

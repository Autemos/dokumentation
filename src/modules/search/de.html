Test Search

Das Test Search Menü bietet eine zentrale Such- und Discovery-Oberfläche für alle Tests innerhalb von Autemos. Die Funktion wurde entwickelt, um schnelle Transparenz über grosse Automatisierungsportfolios hinweg zu ermöglichen.

Test Search Overview — zentrale Tabellenansicht aller Tests mit Suche, Filtern und Pass-Rate-Visualisierung.

Was die Funktion ermöglicht

  • Tests schnell finden
  • Teststatus analysieren
  • Ausführungsqualität überwachen
  • Fehlgeschlagene oder flaky Tests filtern
  • Testdetails einsehen
  • Direkt zu zugehörigen Test Runs navigieren

Zweck

Die Test Search Funktion unterstützt Teams dabei:

  • Tests projektübergreifend zu finden
  • Testqualität zu überwachen
  • Fehlgeschlagene oder instabile Tests zu identifizieren
  • Ausführungsstatistiken zu analysieren
  • Schnell zu Ausführungen zu navigieren
  • Debugging-Workflows zu verbessern
  • Portfolio-weite Transparenz zu schaffen

Filter Optionen

Die Test Search Seite bietet schnelle Filtermöglichkeiten:

All

Alle Tests anzeigen.

Passed

Nur erfolgreich ausgeführte Tests.

Failed

Nur fehlgeschlagene Tests.

Flaky

Nur instabile Tests mit inkonsistentem Verhalten.

Zweck der Filter

  • Instabile Tests isolieren
  • Fehler schneller erkennen
  • Flaky Verhalten analysieren
  • Sich auf stabile Ausführungen konzentrieren

Sichtbarkeit

Projektübergreifende Sichtbarkeit

Die Test Search Funktion arbeitet über alle zugänglichen Projekte hinweg — eine echte portfolio-weite Discovery-Oberfläche.

💡Dadurch können Benutzer projektübergreifend nach Tests suchen, ohne vorher das richtige Projekt auswählen zu müssen — ideal für QA-Teams, die mehrere Projekte parallel betreuen.

Möglichkeiten

  • Global suchen
  • Tests vergleichen
  • Doppelte Tests identifizieren
  • Portfolio-weite Qualität überwachen

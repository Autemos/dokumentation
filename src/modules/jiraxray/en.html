Getting Started

Jira Xray Integration

The Jira Xray integration connects test design in Jira directly with AI-assisted test automation in Autemos.

Existing Xray Test Cases can be selected directly in the Autemos Recorder. Relevant content such as manual test steps, expected results and Cucumber scenarios is transferred to Autemos and used as input for the recording.

The Recorder processes the imported test definition step by step while users can visually follow the automation progress. When the resulting Test Workflow is saved, it remains linked to the original Xray Test Case.

Recorder

Select an Xray Test Case in the Recorder

Start a new Recorder session and open the Test case panel. Search for and select the required Test Case from the connected Jira Xray project.

Depending on the Xray Test Type, Autemos imports the available test definition, including:

  • Jira Issue Key and Test Case title
  • Description and relevant test context
  • Manual test steps, test data and expected results
  • Cucumber / Gherkin scenario steps

The Test Case becomes the functional input for the recording. Users therefore do not need to copy the test definition manually into Autemos.

Select and record Xray Test Cases directly in Autemos.
Recorder

Automating Manual Test Steps

For manual Xray Test Cases, Autemos displays the available test steps in their defined sequence.

The AI Recorder works through the test step by step. During the recording:

  • Completed steps are visually marked
  • The current automation progress remains visible
  • Open steps can be reviewed at any time
  • The AI Chat documents the Recorder actions and any questions that require user input

This provides transparency throughout the automation process and makes it easier to understand how the original Xray Test Case is translated into an executable Test Workflow.

Recorder

Using Cucumber Scenarios

Autemos also supports Xray Test Cases described as Cucumber / Gherkin scenarios.

The scenario is displayed in the Recorder and processed in its original sequence, including steps such as:

StepMeaning
GivenDefines the initial context or precondition
WhenDescribes the user action or event
ThenDefines the expected result
AndAdds further context, actions or validations

As the Recorder automates the scenario, completed steps are visually highlighted. This allows business-readable acceptance scenarios to be used directly as the basis for executable automation.

Import and process Cucumber scenarios step by step.
Recorder

Visual Recording Progress

The Recorder brings the application, AI interaction and Xray Test Case context together in a single view.

During the recording, users can follow:

  • The application currently being automated
  • Recorded browser, mobile or API actions
  • The Test Case steps or Cucumber scenario
  • The number of completed and remaining steps
  • AI messages, questions and the current processing status

This makes the automation process understandable and allows users to intervene when additional functional information is required.

Linking

Linking the Test Workflow to Jira Xray

When the recording is saved, Autemos creates the Test Workflow and automatically links it to the selected Xray Test Case.

The link preserves traceability between the functional test definition in Jira and its technical automation in Autemos. No additional manual mapping is required after the recording.

The linked relationship is visible directly in the Test Workflow and can be removed using the Unlink action if the workflow should no longer be associated with the Test Case.

Usage

Best Practices

  • Keep the Jira Xray Test Case as the functional source of the test definition
  • Write clear, executable test steps with explicit actions and expected results
  • Use Cucumber scenarios when business-readable acceptance criteria are required
  • Review the imported steps before starting the recording
  • Monitor the visual progress and respond to Recorder questions when functional context is missing
  • Use the direct Jira link to review or maintain the original Test Case
  • Unlink a workflow only when the relationship to the Xray Test Case is no longer valid

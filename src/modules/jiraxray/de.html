Jira Xray Integration

Die Jira Xray Integration verbindet das Testdesign in Jira direkt mit der KI-gestützten Testautomatisierung in Autemos.

Bestehende Xray Test Cases lassen sich direkt im Autemos Recorder auswählen. Relevante Inhalte wie manuelle Testschritte, erwartete Ergebnisse und Cucumber-Szenarien werden nach Autemos übernommen und dienen als Eingabe für die Aufzeichnung.

Der Recorder arbeitet die importierte Testdefinition Schritt für Schritt ab, während der Fortschritt visuell verfolgt werden kann. Wird der resultierende Test Workflow gespeichert, bleibt er mit dem ursprünglichen Xray Test Case verknüpft.

Funktionsumfang

Test Case auswählen

Einen bestehenden Xray Test Case direkt im Recorder auswählen.

Testdefinition nutzen

Manuelle Testschritte oder Cucumber-Szenarien als Eingabe für die Aufzeichnung verwenden.

Automatisch verknüpfen

Den gespeicherten Test Workflow automatisch mit dem Xray Test Case verbinden.

Kontext anzeigen

Zentrale Xray-Metadaten einsehen und den verknüpften Test Case direkt aus dem Workflow öffnen.

Recorder

Xray Test Case im Recorder auswählen

Starten Sie eine neue Recorder-Session und öffnen Sie das Panel Test case. Suchen und wählen Sie dort den gewünschten Test Case aus dem verbundenen Jira-Xray-Projekt.

Abhängig vom Xray Test Type importiert Autemos die verfügbare Testdefinition, unter anderem:

  • Jira Issue Key und Titel des Test Case
  • Beschreibung und relevanter Testkontext
  • Manuelle Testschritte, Testdaten und erwartete Ergebnisse
  • Cucumber-/Gherkin-Szenarioschritte

Der Test Case wird damit zur fachlichen Eingabe für die Aufzeichnung. Die Testdefinition muss nicht manuell nach Autemos kopiert werden.

Xray Test Cases direkt in Autemos auswählen und aufzeichnen.
Recorder

Manuelle Testschritte automatisieren

Bei manuellen Xray Test Cases zeigt Autemos die verfügbaren Testschritte in ihrer definierten Reihenfolge an.

Der AI Recorder arbeitet den Test Schritt für Schritt ab. Während der Aufzeichnung gilt:

  • Abgeschlossene Schritte werden visuell markiert
  • Der aktuelle Automatisierungsfortschritt bleibt sichtbar
  • Offene Schritte lassen sich jederzeit einsehen
  • Der AI Chat dokumentiert die Recorder-Aktionen sowie Rückfragen, die eine Eingabe erfordern

Das schafft Transparenz über den gesamten Automatisierungsprozess und macht nachvollziehbar, wie aus dem ursprünglichen Xray Test Case ein ausführbarer Test Workflow entsteht.

Recorder

Cucumber-Szenarien verwenden

Autemos unterstützt auch Xray Test Cases, die als Cucumber-/Gherkin-Szenario beschrieben sind.

Das Szenario wird im Recorder angezeigt und in seiner ursprünglichen Reihenfolge abgearbeitet, einschliesslich der Schritte:

SchrittBedeutung
GivenDefiniert den Ausgangskontext oder die Vorbedingung
WhenBeschreibt die Benutzeraktion oder das Ereignis
ThenDefiniert das erwartete Ergebnis
AndErgänzt weiteren Kontext, Aktionen oder Validierungen

Während der Recorder das Szenario automatisiert, werden abgeschlossene Schritte hervorgehoben. Damit lassen sich fachlich lesbare Akzeptanzszenarien unmittelbar als Grundlage für ausführbare Automatisierung nutzen.

Cucumber-Szenarien importieren und Schritt für Schritt abarbeiten.
Recorder

Visueller Aufzeichnungsfortschritt

Der Recorder führt Anwendung, KI-Interaktion und den Kontext des Xray Test Case in einer Ansicht zusammen.

Während der Aufzeichnung ist nachvollziehbar:

  • Die aktuell automatisierte Anwendung
  • Aufgezeichnete Browser-, Mobile- oder API-Aktionen
  • Die Testschritte beziehungsweise das Cucumber-Szenario
  • Die Anzahl abgeschlossener und verbleibender Schritte
  • KI-Meldungen, Rückfragen und der aktuelle Verarbeitungsstatus

Dadurch bleibt der Automatisierungsprozess verständlich, und es kann eingegriffen werden, sobald zusätzliche fachliche Informationen benötigt werden.

Verknüpfung

Test Workflow mit Jira Xray verknüpfen

Beim Speichern der Aufzeichnung erstellt Autemos den Test Workflow und verknüpft ihn automatisch mit dem ausgewählten Xray Test Case.

Die Verknüpfung erhält die Nachvollziehbarkeit zwischen der fachlichen Testdefinition in Jira und ihrer technischen Automatisierung in Autemos. Ein zusätzliches manuelles Mapping nach der Aufzeichnung ist nicht erforderlich.

Die Verknüpfung ist direkt im Test Workflow sichtbar und lässt sich über die Aktion Unlink wieder entfernen, wenn der Workflow nicht mehr mit dem Test Case verbunden sein soll.

Verknüpfung

In Jira Xray öffnen

Der verknüpfte Issue Key bietet direkten Zugriff auf den ursprünglichen Test Case in Jira Xray. Von der Automatisierung in Autemos gelangt man so unmittelbar zum fachlichen Test Case, ohne ihn in Jira erneut suchen zu müssen.

Anwendung

Best Practices

  • Den Jira Xray Test Case als fachliche Quelle der Testdefinition beibehalten
  • Klare, ausführbare Testschritte mit expliziten Aktionen und erwarteten Ergebnissen schreiben
  • Cucumber-Szenarien verwenden, wenn fachlich lesbare Akzeptanzkriterien gefordert sind
  • Die importierten Schritte vor dem Start der Aufzeichnung prüfen
  • Den visuellen Fortschritt beobachten und auf Rückfragen des Recorders reagieren, wenn fachlicher Kontext fehlt
  • Den direkten Jira-Link nutzen, um den ursprünglichen Test Case zu prüfen oder zu pflegen
  • Einen Workflow nur dann entkoppeln, wenn die Beziehung zum Xray Test Case nicht mehr gültig ist

Erste Schritte

Code Generation

Der Code Generation Hub ermöglicht Teams die automatische Generierung wiederverwendbaren Automation-Codes aus Autemos-Workflows und PageObjects. Er überbrückt die Lücke zwischen visuellem Low-Code-Testdesign und entwicklerbasiertem Quellcode-Management — und erzeugt produktionsreife Automation-Frameworks, die auf Ihren bestehenden Technologie-Stack abgestimmt sind.

Code Generation Hub — Dashboard mit Übersicht über Framework, Project Structure und Sync Profiles auf einen Blick.

Kernfähigkeiten

Automatische Code-Generierung

Wiederverwendbaren Automation-Code direkt aus Test-Workflows, PageObjects, Field Definitions und Actions generieren.

Framework-konformer Output

Generierter Code folgt Framework-Konventionen, Projektstrukturregeln, Benennungsstandards und Template-Definitionen.

Git Synchronization

Generierten Code direkt in GitHub-, GitLab- oder Bitbucket-Repositories pushen — mit Branch-Management und History-Tracking.

Sync Profiles

Wiederverwendbare Synchronisierungs-Konfigurationen für automatisierte, ereignisbasierte oder geplante Code-Auslieferung erstellen.

Konfiguration

Templates

Templates definieren die genaue Code-Struktur, die Autemos für jedes Framework und jeden Feldtyp generiert. Sie steuern Klassenstrukturen, Methoden-Implementierungen, Imports, Framework-Syntax und Feld-Interaktionsmethoden.

Templates — Method Templates geordnet nach Field Type (LINK, TEXT, BUTTON, etc.) mit den verfügbaren Methoden.

Haupt-Templates

Haupt-Templates definieren die übergeordnete Klassenstruktur für jeden generierten Dateityp:

  • Test-Klassenstruktur
  • PageObject-Klassen
  • Konfigurationsdateien
  • Utility-Klassen

Method Templates nach Field Type

Jeder von PageObjects bereitgestellte Feldtyp besitzt eigene Interaktionsmethoden. Diese werden basierend auf dem Feldtyp und dem gewählten Framework generiert:

MethodeZweckBeispiel-Feldtypen
click()Klick-Interaktion auslösenLink, Button
getText()Textinhalt lesenLink, Text
getHref()Hyperlink-URL lesenLink
type()Text in ein Feld eingebenInput
select()Dropdown-Wert auswählenDropdown

Code Template Management

Der Code Template Manager ist eine separate globale Funktion, die als zentrale Engine hinter der Code-Generierung fungiert. Er ermöglicht Teams:

  • Templates für beliebige Sprach- und Framework-Kombinationen anpassen
  • Organisatorische Coding-Standards definieren
  • Wiederverwendbare Generierungs-Logik erstellen
  • Feldspezifische Interaktionsmethoden verwalten

Zugriff über die Schaltfläche Edit in Template Manager im Templates-Tab oder über die globale Sidebar-Navigation.

Code Template Management — Templates, Node-Templates, Methoden & Feldtypen bearbeiten.
Automation

Sync Profiles

Sync Profiles ermöglichen Teams die Automatisierung wiederkehrender Synchronisierungs-Workflows. Ein Profil definiert, welche Workflows und PageObjects synchronisiert werden, den Ziel-Git-Branch, Trigger-Bedingungen und das Planungsverhalten — alles als wiederverwendbare Konfiguration gespeichert.

  • Auswählen, welche Workflows und PageObjects synchronisiert werden
  • Einen dedizierten Git-Ziel-Branch pro Profil definieren
  • Geplante oder ereignisbasierte Sync-Trigger konfigurieren
  • Optional einen Pull Request nach jedem Sync automatisch erstellen
  • Profile unabhängig voneinander aktivieren oder deaktivieren
Neues Sync Profile — Workflows und PageObjects zur Einbeziehung auswählen.

Profil-Konfiguration

EinstellungBeschreibung
Tests (Workflows)Auswählen, welche Workflows einbezogen werden. Referenzierte PageObjects werden automatisch erkannt.
Page ObjectsAutomatisch anhand von Workflow-Referenzen ausgewählt oder manuell hinzugefügt.
Git Target BranchDedizierter Branch für dieses Profil (z. B. codegen/profile-name-sync)
SchedulePeriodische Synchronisierung aktivieren (nächtlich, täglich, etc.)
Event TriggersAutomatisch synchronisieren, wenn bestimmte Ereignisse eintreten
Auto-create PRNach jedem Sync automatisch einen Pull Request zur Überprüfung öffnen
ActiveProfil unabhängig aktivieren oder deaktivieren

Ereignisbasierte Trigger

TriggerBeschreibung
Run on Workflow SaveAutomatisch synchronisieren, wenn ein Workflow geändert und gespeichert wird
Run on Successful Test RunNach einer erfolgreichen Ausführung synchronisieren — hält das Repository stets aktuell
💡Aktivieren Sie Auto-create PR zusammen mit Event-Triggern, um für jede automatisch generierte Änderung eine Code-Review zu erzwingen — ideal für CI/CD-Pipelines, die kontrollierte Merges erfordern.

Der Generate-Tab ermöglicht manuelle, bedarfsgesteuerte Code-Generierung. Workflows und PageObjects zur Einbeziehung auswählen, das Output-Format wählen und sofort generieren.

Automation

Git Sync

Der Git Sync-Tab bietet direktes Repository-Management — Git-Verbindung konfigurieren, Code manuell pushen und die vollständige Synchronisierungshistorie einsehen.

Git Sync — Provider, Repository-URL, Zugriffstoken und Branch konfigurieren. Sync History verfolgt alle früheren Pushes.

Git-Verbindung

Unterstützte Provider: GitHub, GitLab, Bitbucket. Repository-URL, persönlichen Zugriffstoken und Standard-Branch konfigurieren. Test Connection verwenden, um vor dem Speichern zu validieren.

Sync History

Die Sync History bietet vollständige Transparenz über jeden vorherigen Synchronisierungs-Lauf:

  • Zeitstempel jeder Synchronisierung
  • Push-Ergebnis (Erfolg oder Fehler)
  • Verwendeter Branch
  • Fehlerdetails für Debugging

Externe Integration & CI/CD

Code-Generierung und Synchronisierung können auch extern via API ausgelöst werden. Dies unterstützt die Integration mit:

  • GitLab CI Pipelines
  • Jenkins Jobs
  • GitHub Actions Workflows
  • Benutzerdefinierten Deployment-Pipelines
💡Kombinieren Sie externe API-Trigger mit Sync Profiles für eine vollautomatische Code-Generierungs-Pipeline — generieren, pushen und einen PR automatisch als Teil jedes Deployment-Zyklus öffnen.

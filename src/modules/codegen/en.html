Getting Started

Code Generation

The Code Generation Hub enables teams to automatically generate reusable automation code from Autemos workflows and PageObjects. It bridges the gap between visual low-code test design and developer-driven source code management — producing production-ready automation frameworks aligned with your existing technology stack.

Code Generation Hub — Dashboard with an at-a-glance overview of Framework, Project Structure and Sync Profiles.

Core Capabilities

Automatic Code Generation

Generate reusable automation code directly from test workflows, PageObjects, field definitions and actions.

Framework-Compliant Output

Generated code follows framework conventions, project structure rules, naming standards and template definitions.

Git Synchronization

Push generated code directly to GitHub, GitLab or Bitbucket repositories — with branch management and history tracking.

Sync Profiles

Create reusable synchronization configurations for automated, event-driven or scheduled code delivery.

1

2

3

Getting Started

Dashboard

The Dashboard provides a centralized overview of the current code generation configuration. It shows the status of all three core configuration areas at a glance and allows direct access for editing each one.

Framework Overview

Displays the selected language, framework configuration and package namespace. Shows Configured once setup is complete.

Project Structure Overview

Shows the configured output paths for tests, PageObjects and configuration files with a live count of mapped files.

Sync Profiles Overview

Lists existing synchronization profiles, their status, and provides a shortcut to create new profiles.

Configuration

Setup

The Setup section configures the technical foundation of the generated automation project. It places Framework Settings and Git Connection side by side and includes a Danger Zone for resetting the configuration.

Setup tab — Framework Settings (left) and Git Connection (right) configured side by side.

Framework Settings

SettingDescription
LanguageProgramming language (Java, TypeScript, Python, C#)
FrameworkAutomation framework (Selenium, Playwright, Appium)
Package NameRoot package namespace (e.g. ch.eribank.test)
Base URLDefault application URL for the generated project
Test RunnerTest execution engine (TestNG, JUnit, Vitest, Jest)

Git Connection

FieldDescription
ProviderGit provider — GitHub, GitLab or Bitbucket
Repository URLTarget repository for code synchronization
Access TokenPersonal access token used for authentication
Default BranchBranch used for synchronization (e.g. main)

Use Test Connection to validate repository access, authentication, branch availability and write permissions before enabling synchronization.

💡The Danger Zone at the end of Setup allows resetting the project configuration. This removes framework settings and restarts the wizard — templates and project structure are preserved.

Setup Wizard

New projects use a guided 4-step wizard to configure the code generation foundation.

Step 1 — Choose a platform: Web, Mobile or Web + Mobile.
Step 2 — Select the automation framework combination.
Step 3 — Enter the package name and base URL for the project.
Step 4 — Review the complete configuration before finalizing setup.
Configuration

Project Structure

The Project Structure section defines how generated files are organized in the target repository. Output paths use dynamic placeholders that are resolved at generation time.

Project Structure — Configure output paths and preview the generated folder tree before generation.

Configurable Output Paths

PathExamplePurpose
Test Output Pathsrc/test/java/{packagePath}/Where test class files are generated
PageObject Output Pathsrc/main/java/{packagePath}/pages/Where PageObject class files are generated
Config Output PathoptionalWhere supporting configuration files are placed

Dynamic Placeholders

PlaceholderResolved Value
{packagePath}Package name as a directory path (e.g. ch/eribank/test)
{TestName}Name of the generated test class
{PageName}Name of the generated PageObject class

A live folder tree preview visualizes the complete generated project structure based on the current path configuration — before any code is generated.

Configuration

Templates

Templates define the exact code structure that Autemos generates for each framework and field type. They control class structures, method implementations, imports, framework syntax and field interaction methods.

Templates — Method Templates grouped by Field Type (LINK, TEXT, BUTTON, etc.) with the available methods.

Main Templates

Main templates define the top-level class structure for each generated file type:

  • Test class structure
  • PageObject classes
  • Configuration files
  • Utility classes

Method Templates by Field Type

Every field type provided by PageObjects has its own interaction methods. These are generated based on the field type and the selected framework:

MethodPurposeExample Field Types

getHref()Read hyperlink URLLink
type()Enter text into a fieldInput

Code Template Management

The Code Template Manager is a separate global feature that acts as the central engine behind code generation. It allows teams to:

  • Customize templates for any language and framework combination
  • Define organizational coding standards
  • Create reusable generation logic
  • Manage field-specific interaction methods

Access via the Edit in Template Manager button in the Templates tab or through the global sidebar navigation.

Code Template Management — Edit templates, node templates, methods & field types.
Automation

Sync Profiles

Sync Profiles allow teams to automate recurring synchronization workflows. A profile defines which workflows and PageObjects to synchronize, the target Git branch, trigger conditions and scheduling behavior — all stored as a reusable configuration.

  • Select which workflows and PageObjects to synchronize
  • Define a dedicated target Git branch per profile
  • Configure scheduled or event-driven sync triggers
  • Optionally create a pull request automatically after each sync
  • Enable or disable profiles independently
New Sync Profile — Select workflows and PageObjects to include.

Profile Configuration

SettingDescription
Tests (Workflows)Select which workflows to include. Referenced PageObjects are detected automatically.
Page ObjectsAutomatically selected from workflow references or added manually.
Git Target BranchDedicated branch for this profile (e.g. codegen/profile-name-sync)
ScheduleEnable periodic synchronization (nightly, daily, etc.)
Event TriggersSynchronize automatically when specific events occur
Auto-create PRAutomatically open a pull request for review after each sync
ActiveEnable or disable the profile independently

Event-Driven Triggers

TriggerDescription
Run on Workflow SaveSynchronize automatically when a workflow is changed and saved
Run on Successful Test RunSynchronize after a successful execution — keeps the repository continuously up to date
💡Enable Auto-create PR together with event triggers to enforce a code review for every automatically generated change — ideal for CI/CD pipelines that require controlled merges.
Automation

Generate

The Generate tab enables manual, on-demand code generation. Select workflows and PageObjects to include, choose the output format and generate immediately.

Generate tab — Select tests and PageObjects, then preview, download as ZIP or push to Git.

Selection

  • Select individual workflows in the Tests panel — or use Select All
  • Referenced PageObjects are detected automatically when a workflow is selected
  • Additional PageObjects can be added manually from the Page Objects panel

Generation Options

OptionDescription
Include Test FilesGenerate executable test class files for the selected workflows
Include Config FilesGenerate framework configuration and supporting assets

Output Options

Preview

Review the generated code before downloading or pushing — verify file names, structure and content.

Generate & Download ZIP

Download the complete generated project as a ZIP archive for local use or manual integration.

Push to Git

Push the generated code directly to the configured Git repository and branch.

Automation

Git Sync

The Git Sync tab provides direct repository management — configure the Git connection, push code manually and view the full synchronization history.

Git Sync — Configure provider, repository URL, access token and branch. Sync History tracks all previous pushes.

Git Connection

Supported providers: GitHub, GitLab, Bitbucket. Configure the repository URL, personal access token and default branch. Use Test Connection to validate before saving.

Sync History

The Sync History provides full transparency for every previous synchronization run:

  • Timestamp of each synchronization
  • Push result (success or failure)
  • Branch used
  • Error details for debugging

External Integration & CI/CD

Code generation and synchronization can also be triggered externally via API. This supports integration with:

  • GitLab CI Pipelines
  • Jenkins Jobs
  • GitHub Actions Workflows
  • Custom deployment pipelines
💡Combine external API triggers with Sync Profiles for a fully automated code generation pipeline — generate, push and open a PR automatically as part of every deployment cycle.

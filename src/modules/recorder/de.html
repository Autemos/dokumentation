Erste Schritte

Recorder

Der Recorder ist der schnellste Weg, automatisierte Tests in Autemos zu erstellen. Statt Workflows manuell Schritt für Schritt aufzubauen, können Benutzer einfach mit der Anwendung interagieren, während Autemos sämtliche Aktionen automatisch aufzeichnet und in wiederverwendbare Test Workflows umwandelt.

Der Recorder unterstützt zwei Recording-Modi:

  • Manual Recording — klassischer Click-Recorder
  • AI Recording — KI-gestützte Testerstellung über natürliche Sprache

Während der Aufnahme erstellt Autemos automatisch Pages und Fields, Workflow Nodes, Assertions, Reusable Selectors, Page Objects sowie Tabellen- und UI-Strukturen. Der erzeugte Workflow kann anschliessend gespeichert und im Test Workflow Editor weiterbearbeitet werden.

Hauptfunktionen

Dual Recording Modes

Wählen zwischen klassischer Interaktionsaufzeichnung (Manual) und KI-gesteuerter Testerstellung über natürliche Sprache (AI).

Web & Mobile Support

Unterstützung für Browser-basierte Anwendungen sowie Mobile Automation auf Android, iOS, physischen Geräten und Device Farms.

Automatische Page Object Erkennung

Pages, Fields und Selectors werden während der Aufzeichnung automatisch erkannt und als wiederverwendbare Komponenten erstellt.

Workflow Ready

Der generierte Workflow steht sofort im Test Workflow Editor zur Weiterbearbeitung und Ausführung bereit.

Erste Schritte

Recorder Workspace

Der Recorder bietet eine zentrale Oberfläche zum Aufzeichnen, Analysieren und Speichern von Testabläufen. Der Workspace ist in klar getrennte Bereiche unterteilt, die während einer Session zusammenarbeiten.

Hauptbereiche

  • Session Area — Anzeige der aktiven Browser- oder Mobile-Session
  • AI Chat Panel — Interaktion mit der KI über natürliche Sprache (AI-Modus)
  • Events Panel — zeigt alle aufgezeichneten technischen Events in Echtzeit
  • Workflow View — Visualisierung des generierten Test Workflows
  • Pages View — Anzeige der automatisch erkannten Pages und Fields
Recorder Workspace — Manual- und AI-Modus, Events / Workflow / Pages Tabs.
Session Management

Session starten

Benutzer können direkt aus dem Recorder neue Sessions starten. Unterstützte Session-Typen: Web Browser und Mobile Device.

Web Browser Session

Konfigurieren Sie die Browser-Session über eine vordefinierte Anwendung und Umgebung oder geben Sie eine URL direkt ein.

FeldBeschreibung
ApplicationAuswahl einer definierten Anwendung
EnvironmentAuswahl der Zielumgebung (DEV, QA, UAT, PROD)
BrowserAuswahl des Zielbrowsers
CertificateEinbindung von persönlichen oder projektweiten Zertifikaten
Resolved URLAnzeige der final geöffneten URL
Web Browser Session — Application, Environment, Browser und Certificate auswählen.

Direkte URL-Aufzeichnung

Alternativ kann direkt eine URL eingegeben werden, ohne Application oder Environment auszuwählen. Ideal für Ad-hoc-Tests, externe Webseiten, temporäre Umgebungen und Schnelltests.

💡Verwenden Sie Enter URL manually, wenn das Ziel nicht als Autemos-Anwendung registriert ist — die Session wird nicht an eine Projektumgebung gebunden.
Direkte URL-Eingabe — ohne Application oder Environment starten.

Session Management

Manual Recording

Der Manual Recorder eignet sich für Benutzer, die direkt mit der Anwendung arbeiten möchten, während Autemos sämtliche Aktionen automatisch aufzeichnet.

Funktionsweise

Starten Sie eine Session, interagieren Sie mit der Anwendung und beenden Sie den Ablauf. Autemos zeichnet automatisch auf:

  • Clicks und Inputs
  • Navigation und Page Transitions
  • Assertions und Element-Interaktionen

Automatisch erzeugte Artefakte

Workflow Nodes

Jede aufgezeichnete Aktion wird zu einem Node im visuellen Workflow.

Page Objects

Pages und Fields werden automatisch erkannt und als wiederverwendbare Komponenten erstellt.

Assertions

Validierungsschritte werden automatisch zusammen mit den Interaktions-Events erfasst.

Reusable Selectors

Pro Element werden mehrere Selektorstrategien generiert für langfristige Stabilität.

Session Management

AI Recording

Mit dem AI Recorder können Benutzer Tests vollständig über natürliche Sprache erstellen. Wechseln Sie in den AI-Modus und beschreiben Sie das gewünschte Szenario im AI Chat Panel.

💡Beispiel: „Öffne eBanking, navigiere zu Budget, öffne Hilfe und Kontakt und prüfe die Telefonnummer."

Die KI interpretiert die Eingabe, führt die Aktionen aus, navigiert durch die Anwendung und erstellt automatisch den vollständigen Workflow.

AI-Modus — AI Chat Panel und Modell-Selektor (z. B. GPT-4o).

Transparente KI-Ausführung

Während der AI-Ausführung zeigt Autemos live an:

  • Ausgeführte Commands und Browser-Aktionen
  • Generierte Workflow Nodes und Page Objects
  • Durchgeführte Assertions
  • Zusammenfassung der Ausführung
KI-Ausführungsübersicht — Schritte und Ergebnisse werden im Chat angezeigt.

Unterstützte AI Models

Der Recorder unterstützt konfigurierbare AI Models (z. B. GPT-4o), die je nach Projektanforderung ausgewählt werden können.

Aufgezeichnete Daten

Events Recording

Der Events-Tab zeigt sämtliche aufgezeichneten technischen Aktionen mit vollständigen Details.

Typische Events

  • open_browser()
  • click_element()
  • assert_element()
  • close_session()

Event-Details

Jedes Event enthält: Event Type, Selector, Page Object Referenzen, Parameter, Assertion Values sowie Browser- oder Device-Kontext. Events können nach Web, Mobile und Event Type gefiltert werden.

Events-Tab — alle aufgezeichneten Aktionen mit Typ, Selector und Page Object Referenzen.
Aufgezeichnete Daten

Workflow-Generierung

Autemos wandelt die aufgezeichneten Events automatisch in einen visuellen Workflow um. Der Workflow-Tab zeigt den generierten Graphen in Echtzeit.

Inhalt des Workflows

  • Navigation Nodes (Open Browser, Close)
  • Action Nodes (Click, Type, Swipe)
  • Assertions und Session Handling
  • Ablaufreihenfolge und bedingte Logik

Wiederverwendbarkeit

Die erzeugten Workflows können bearbeitet, kombiniert, geplant, ausgeführt und für Code Generation verwendet werden.

Workflow-Tab — der generierte Workflow-Graph aktualisiert sich in Echtzeit.
Aufgezeichnete Daten

Automatische Page Object Erkennung

Eine der wichtigsten Funktionen des Recorders ist die automatische Erstellung von Page Objects. Autemos erkennt während der Aufnahme kontinuierlich UI-Strukturen und erstellt daraus wiederverwendbare Komponenten.

Automatisch erkannte Elemente

  • Pages, Fields, Buttons, Inputs, Links
  • Tabellen und UI-Strukturen
  • Assertions und Selectors

Reuse Detection

Autemos erkennt automatisch bereits existierende Elemente und markiert sie als Reused oder New — Duplikate werden vermieden, die Wartbarkeit verbessert.

Pages-Tab — erkannte Page Objects und Fields, markiert als Reused oder New.
Ausgabe & Integration

Recorder Output

Nach dem Speichern erstellt der Recorder automatisch einen vollständigen Satz wiederverwendbarer Assets:

Test Workflow

Wiederverwendbarer Workflow zur Ausführung und Bearbeitung im Test Workflow Editor.

Page Objects

Strukturierte Seitenmodelle mit Fields und Selectors.

Assertions

Automatisch erfasste Validierungslogik, direkt im Workflow eingebettet.

Event Metadata

Technische Informationen zur Ausführung für Debugging und Audit.

Integration mit dem Test Workflow Editor

Nach dem Speichern kann der erzeugte Workflow im Test Workflow Editor erweitert werden: Bedingungen, Schleifen, Variablen, Retry-Logik, Integrationen und erweiterte Assertions. Der Recorder dient als Grundlage für komplexe Enterprise-Testautomatisierung.

Integration mit Code Generation

Die erzeugten Workflows können direkt im Code Generation Hub verwendet werden, um automatisierten Testcode für Selenium, Playwright oder Appium zu generieren.

Als Test Workflow oder Sub-Workflow speichern

Beim Speichern einer Recording Session kann gewählt werden, ob die aufgezeichneten Schritte als Test Workflow oder als Sub-Workflow abgelegt werden.

Ein Sub-Workflow eignet sich, wenn der aufgezeichnete Prozess in mehreren Tests verwendet werden soll, nur einen Teil eines vollständigen Tests darstellt, wiederverwendbare Eingabeparameter benötigt oder zentral gepflegt werden soll. Weitere Wege zur Erstellung beschreibt Sub-Workflow erstellen und extrahieren.
